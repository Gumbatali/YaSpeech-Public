YaSpeech MVP

Веб-обёртка над Yandex Cloud сервисами для обработки аудиозаписей встреч и выпуска протоколов.

Бизнес-контекст

Проблема

Записи встреч плохо превращаются в рабочие артефакты.

Цель

Дать пользователю быстрый путь от аудио к протоколу.

Ограничение

Минимум облачных расходов и только допустимый стек.
