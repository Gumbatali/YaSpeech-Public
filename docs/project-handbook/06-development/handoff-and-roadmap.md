# Handoff и roadmap

## Что уже есть

- локально работающий MVP;
- mobile-first интерфейс;
- сценарий `проект -> загрузка файла -> черновик -> протокол`;
- JSON-хранилище;
- draft-step для подтверждения названия и спикеров;
- mock-слой вместо реальных Yandex интеграций.

## Что ещё не сделано

- настоящие адаптеры к `SpeechKit`;
- настоящие адаптеры к `YandexGPT`;
- реальное облачное развёртывание;
- production-конфиг и IAM;
- observability-панель уровня production.

## Рекомендуемая следующая итерация

### Этап 1. Cloud enablement

- создать ресурсы в Yandex Cloud;
- разложить фронтенд в Object Storage;
- вынести backend в Cloud Functions;
- настроить очередь и API Gateway.

### Этап 2. Реальные интеграции

- заменить mock `SpeechKitGateway`;
- заменить mock `YandexGptGateway`;
- добавить конфиг окружения;
- провести первый end-to-end прогон на реальном аудио.

### Этап 3. Product hardening

- улучшить тексты ошибок;
- улучшить draft matching по людям проекта;
- добавить экспорт в дополнительные форматы;
- добавить наблюдаемость и алерты.

## Чек-лист передачи проекта

- прочитать `docs/project-handbook/README.md`;
- прочитать `03-solution-architecture`;
- прочитать `04-system-analysis`;
- проверить `05-delivery-and-operations`;
- сверить реальные облачные роли и ресурсы;
- заменить mock-адаптеры на реальные интеграции;
- прогнать smoke test.
