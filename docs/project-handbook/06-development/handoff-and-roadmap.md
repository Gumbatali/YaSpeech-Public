# Handoff и roadmap

## Что уже сделано

- развёрнут в production в Яндекс Облаке (Object Storage, YMQ, Cloud Functions, API Gateway);
- реальные интеграции SpeechKit и YandexGPT работают в проде;
- mock-слой сохранён для локальной разработки и тестов;
- личные кабинеты: вход по логину/паролю, роли (admin/member), квоты, бан;
- сценарий `проект → загрузка → черновик → протокол`, mobile-first UI;
- **LLM-улучшение расшифровки по кнопке** (диаризация, глоссарий, коррекция ASR
  с line-ID протоколом и валидатором чисел, имена спикеров);
- редактирование расшифровки и итогов, возврат к оригиналу, пересборка протокола;
- итеративный цикл `правка → ИИ → правка → протокол` с защитой от гонки;
- память проекта: перенос задач и накопительный словарь терминов;
- **CI/CD**: автотесты на каждый PR, автодеплой при мерже в `main`;
- 54 теста (unit + API e2e + smoke).

## Архитектурный инвариант (не нарушать)

> **Ноль автоматических LLM-вызовов.** Всё, что обращается к YandexGPT,
> запускается только по явной кнопке пользователя. Это держит расходы
> предсказуемыми. Любой новый код должен этому подчиняться.

## Технический долг и следующие шаги

### 🔴 Приоритет 1 — мешает разработке

- **Распил `apps/web/app/app.js`** (~1580 строк, один компонент, ~44 хука).
  Резать по экранам (projects-list, meeting-detail, draft-editor) с явным
  прокидыванием состояния. `summary-tab` и `transcript-tab` уже вынесены —
  продолжить тем же паттерном.

### 🟠 Приоритет 2 — риск консистентности / эксплуатации

- **Два индекса встреч** (глобальный `meetings/index.json` + проектный) могут
  разъехаться. Выбрать source of truth, второй сделать производным.
  Диагностика уже есть: `scripts/reconcile-indexes.sh`.
- **`delete()` оставляет файлы в S3** — orphan-данные (включая аудио) копятся.
  Добавить очистку артефактов при удалении встречи/проекта.
- **Внешний healthcheck и алерты** — настроить по
  [monitoring-and-logging.md](../05-delivery-and-operations/monitoring-and-logging.md).

### 🟡 Приоритет 3 — продуктовое и hardening

- API-ключ на уровне Gateway через Lockbox (перед серьёзным прод-трафиком).
- Пути в Object Storage строго по спеке (`audio.mp3` вместо `audio-original.mp3`).
- Сверка с предыдущим протоколом + автоматический перенос незакрытых задач.
- Экспорт протокола в дополнительные форматы (docx).
