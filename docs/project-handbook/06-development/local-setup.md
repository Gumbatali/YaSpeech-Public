# Локальная разработка

Как развернуть YaSpeech на своей машине и что при этом работает «по-настоящему»,
а что — на mock-заглушках.

---

## Требования

- **Node.js 18+** — единственное обязательное требование для разработки.
- **Python 3 + boto3** — нужны только для деплоя фронтенда (`deploy.sh`), не для разработки.
- **Yandex Cloud CLI** — только если будешь деплоить руками.

Зависимостей npm нет — `npm install` запускать не нужно.

---

## Запуск

```bash
git clone git@github.com:Gumbatali/YaSpeech.git
cd YaSpeech

npm test        # 54 теста, проверка что всё на месте
npm run dev     # поднимает http://127.0.0.1:8787
```

Открой http://127.0.0.1:8787 — это полноценный SPA на mock-данных.

### Что работает локально на mock-адаптерах

| Компонент в проде | Локальная замена |
|-------------------|------------------|
| Object Storage | JSON-файлы на диске (`LocalArtifactStorage`, папка `.local-data/`) |
| Message Queue (YMQ) | In-process очередь (`LocalQueueRunner`) |
| SpeechKit (ASR) | `MockSpeechKitGateway` — отдаёт заранее заготовленный транскрипт |
| YandexGPT (LLM) | `MockYandexGptGateway` — детерминированный «протокол» без вызова сети |

Это значит: можно пройти весь сценарий (проект → загрузка → черновик →
улучшение ИИ → протокол) полностью офлайн и бесплатно.

Данные пишутся в `.local-data/` (в `.gitignore`). Чтобы начать с чистого листа —
удали папку.

## Запуск с аутентификацией

По умолчанию dev-сервер не требует логина. Чтобы включить вход по логину/паролю
и роль администратора:

```bash
SESSION_SECRET=dev-secret-local ADMIN_LOGIN=admin node apps/server/src/dev-server.js
```

- `SESSION_SECRET` — соль для подписи сессионных cookie (локально — любая строка).
- `ADMIN_LOGIN` — логин, который при регистрации получит роль `admin`
  автоматически. Зарегистрируйся под ним → станешь администратором.

---

## Запуск против реальных Yandex Cloud API (опционально)

Иногда нужно проверить настоящий SpeechKit/YandexGPT, не выкатывая в прод.
Для этого нужны реальные ключи (см.
[iam-and-access.md](../05-delivery-and-operations/iam-and-access.md)) в переменных
окружения. Без них сервер сам выбирает mock-адаптеры — это безопасное поведение
по умолчанию.

> ⚠️ Вызовы реального YandexGPT/SpeechKit платные. Локально по умолчанию они
> выключены намеренно.

## Частые команды

```bash
npm test                                  # все тесты
node --test apps/server/tests/api.test.js # один файл тестов
npm run dev                               # dev-сервер на :8787
npm run build                             # копирует apps/ + packages/ в dist/ (для упаковки)
```

> `npm run build` — это не транспиляция (babel/webpack нет), а простое копирование
> исходников в `dist/`. Браузер исполняет ES-модули напрямую.

## Превью в Claude Code

В `~/.claude/launch.json` есть конфиг `yaspeech-dev` (порт 8787) — его можно
запускать через preview-инструменты Claude Code для проверки UI-изменений.
