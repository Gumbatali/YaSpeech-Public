# Руководство пользователя

Как пользоваться YaSpeech от входа до готового протокола. Без технических
подробностей — только то, что видно на экране.

> Хотите сперва понять идею сервиса? См.
> [«Как это работает — простыми словами»](./КАК-ЭТО-РАБОТАЕТ.md).

---

## С чего всё начинается

Работа идёт по простой цепочке:

```
Вход  →  Проект  →  Загрузка записи  →  Расшифровка  →  (по желанию) улучшение ИИ  →  Протокол
```

Каждый шаг — отдельный экран. Сервис ведёт вас по нему сам: подсказывает, что
делать дальше, и показывает статус обработки.

---

## 1. Вход

На первом экране — поля **«Имя пользователя»** и **«Пароль»**.

- Если аккаунт уже есть — введите данные и нажмите **«Войти»**.
- Если входите впервые — переключитесь на **«Регистрация»**, придумайте логин и
  пароль и нажмите **«Зарегистрироваться»**.

У каждого пользователя свои проекты — чужих встреч вы не видите.

---

## 2. Проект

Проект — это контекст, внутри которого живут встречи. Обычно один проект = один
объект или одна тема (например, конкретная стройка).

1. Нажмите **«Новый проект»**, дайте ему название.
2. По желанию заполните **«Состав проекта»** — участников, которые регулярно
   бывают на встречах.

Зачем нужен состав: когда сервис разбирает запись, он сверяет голоса с этим
списком и точнее подписывает, кто что сказал. Это необязательно, но заметно
улучшает результат.

---

## 3. Загрузка записи

Внутри проекта нажмите **«Новая встреча»** → **«Загрузить запись»** и выберите
аудиофайл.

Поддерживаются MP3, M4A, WAV, OGG, FLAC и голосовые сообщения из мессенджеров.
Файл загружается напрямую — большие записи не упираются в ограничения.

После загрузки сервис ставит встречу в очередь и начинает обработку. Статус
меняется сам, страницу обновлять не нужно:

| Что видно на экране | Что происходит |
|---------------------|----------------|
| «Поставили встречу в очередь…» | Запись принята, ждёт обработки |
| «Готовим текст встречи» | Идёт распознавание речи |
| Черновик готов | Можно читать и править |

Распознавание занимает одну-две минуты и **бесплатно** — здесь искусственный
интеллект ещё не подключается.

---

## 4. Черновик расшифровки

Когда текст готов, открывается черновик: реплики с таймкодами, разбитые по
спикерам. Это дословная расшифровка — какой её услышала система, ещё без правок.

На этом шаге стоит:

- **проверить название встречи** и поправить, если нужно;
- **проверить имена спикеров** — система проставляет их предположительно;
- при желании **поправить любую реплику** вручную. Подсказка на экране:
  «Исправьте текст — ИИ и протокол будут работать с вашей версией». После правок
  нажмите **«Сохранить»**.

Дальше есть две дороги: сразу собрать протокол или сначала улучшить текст с
помощью ИИ.

---

## 5. Улучшение с помощью ИИ (по желанию)

Кнопка **«Улучшить с помощью ИИ»** запускает языковую модель, которая:

- аккуратнее **разделяет реплики по говорящим**;
- **исправляет ошибки распознавания** по смыслу (профессиональные термины,
  обрезанные слова). Числа и даты при этом отдельно проверяются, чтобы ИИ
  случайно их не подменил;
- **уточняет, кто есть кто** — по обращениям в разговоре.

Пока модель работает, видно «Готовим текст встречи». После — появляются **две
версии** текста: дословная и улучшенная. Вы сами решаете, какой доверять.

> Этот шаг необязателен. Если расшифровка и так читается нормально — можно сразу
> переходить к протоколу.

**Если что-то пошло не так:** кнопка **«↩️ Вернуть оригинал»** возвращает
исходную расшифровку от системы распознавания (все ручные правки текста при этом
теряются — сервис об этом предупредит).

---

## 6. Протокол

Когда текст вас устраивает, нажмите **«Собрать протокол»**. Модель собирает
готовый документ:

- краткое описание встречи;
- участники;
- принятые решения;
- задачи — с ответственными и сроками.

Пока идёт сборка, видно «Собираем итоговый протокол». Готовый протокол можно:

- **«Скопировать итоги»** — весь текст в буфер обмена;
- **«Скачать TXT»** — сохранить файлом (доступны и дословная, и улучшенная версии);
- **«Сохранить итоги»** — отредактировать любой пункт прямо в браузере.

**Поправили расшифровку после сборки?** Нажмите **«🔄 Пересобрать протокол»** —
итоги соберутся заново уже на основе ваших исправлений.

---

## Память проекта

Сервис помнит прошлые встречи внутри одного проекта, и это даёт две вещи:

1. **Перенос задач** — незакрытая задача с прошлой встречи попадёт в новый
   протокол, пока её не отметят выполненной.
2. **Словарь терминов** — специфические слова проекта (марки материалов, узлы,
   фамилии) со временем распознаются точнее.

---

## Если вы администратор

У администратора есть отдельный раздел управления пользователями: можно
заблокировать пользователя, назначить роль и задать квоту — сколько расшифровок
человек может сделать.

Вход в админский аккаунт защищён **двумя факторами**: после пароля система
попросит 6-значный код из приложения-аутентификатора (Google Authenticator,
1Password и т.п.). Это не даёт зайти в админку, даже если пароль кто-то узнал.
При первой настройке выдаются одноразовые коды восстановления — сохраните их на
случай потери телефона.

---

## Коротко

Войти → создать проект → загрузить запись → получить расшифровку → при желании
улучшить её ИИ → собрать протокол → поправить и скачать. Дословная расшифровка
бесплатна и готова за минуту; всё, что дороже, запускается только вашей кнопкой.
