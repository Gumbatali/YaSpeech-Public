# Runbook

## Ежедневная операционная модель

- проверять, что сайт открывается;
- проверять, что API отвечает;
- проверять, что новые встречи переходят по стадиям;
- проверять, что очереди не копят сообщения бесконечно;
- проверять, что worker не падает системно на одних и тех же шагах.

## Smoke test после релиза

1. Открыть список проектов.
2. Открыть один проект.
3. Загрузить тестовый аудиофайл.
4. Дождаться `draft_ready`.
5. Подтвердить черновик.
6. Дождаться `done`.
7. Скачать `protocol.txt`.

## Что смотреть при ошибке

### Ошибка загрузки

Проверить:

- upload URL;
- права на бакет;
- наличие файла в Object Storage.

### Ошибка транскрипции

Проверить:

- логи worker;
- доступы к SpeechKit;
- корректность формата аудио.

### Ошибка генерации протокола

Проверить:

- логи worker;
- доступы к YandexGPT;
- наличие `transcript.json`.

### Зависшие встречи

Проверить:

- очередь сообщений;
- триггер worker-функции;
- нет ли встречи в промежуточном статусе без новых логов.

## Правило ручного восстановления

Если встреча ушла в `failed`, пользователь должен иметь возможность безопасно нажать `retry` без ручного редактирования артефактов.

## Диагностика (Служебные скрипты)

```bash
# Проверить согласованность индексов встреч в Object Storage
bash scripts/reconcile-indexes.sh          # dry-run
bash scripts/reconcile-indexes.sh --apply  # применить исправления
```
